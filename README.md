## How to Use

1. Upload the entire `rrevent` folder to your web host (or point domain to it).
2. Open `index.html` in a browser to preview locally.
3. For free live chat: the floating green button opens WhatsApp (no third-party account needed).

## Folder Structure

```
rrevent/
├── index.html
├── css/style.css
```

## Customisation Tips

- Replace stock images in `images/` with your real wedding photos.
- Update package prices in the Pricing section of `index.html`.
- Change colours in `css/style.css` under `:root` variables.
